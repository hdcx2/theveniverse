# Disease CAD and 3D Models

Place disease-related model files in this folder, grouped by the condition they illustrate. Keep a short note with each model describing the anatomy shown, source, creator, and intended educational use.

Suggested layout:

```text
models/
  venous/
  lymphatic/
  capillary/
  avms/
```

Common formats include STL, OBJ, GLB/GLTF, STEP, and IGES. The site currently has a model section on each vascular-malformation page, but it does not yet render interactive CAD files. When you add files, I can link previews/downloads or add an interactive viewer that supports the formats you provide.
